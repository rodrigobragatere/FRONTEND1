Ambiente de Programação

07

CSS — Entendendo sobre estilos

Prática 7 — três formas de aplicar CSS: Inline, Interno e Externo.

Inline

Estilo aplicado diretamente no atributo style da tag.

Este texto usa CSS inline. 

<p style="color: #0056b3;">...</p>

Interno

Regras dentro de <style> no <head> desta página.

Este bloco usa a classe .demo-interno definida internamente.

<style>
  .demo-interno { ... }
</style>

Externo

Arquivo separado (css/styles.css) ligado com <link>.

Toda a identidade visual deste site vem do CSS externo.

<link rel="stylesheet"
  href="css/styles.css">

Prática — troque o tema
